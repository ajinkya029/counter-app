# 🔢 Counter App

A simple and interactive **Counter App** built with **React.js** and **Vite**. The app allows users to increment, decrement, and reset a counter using a clean and responsive interface.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/counter-app.git
```

### 2. Navigate to the project

```bash
cd counter-app
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL shown in the terminal.
